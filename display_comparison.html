How to read this dashboard. D-1 is the display count reported on each outlet’s latest (max) visit date; D-2 is the count on that outlet’s second-latest visit date. Change = D-1 − D-2 and Change % = Change ÷ D-2. Product types are shown as TV (LED), AC and WM (Washing Machine). Outlet basis: “All outlets” compares every outlet (outlets with a single visit contribute D-1 only, shown as new); “Like-for-like” keeps only outlets that have both a D-1 and a D-2 visit. Visit dates are always determined per outlet across all products, so product filters never shift an outlet’s D-1 / D-2 dates. Source sheet: Display Data-Raw.
